Entry for the [make.fun "In Airplane Mode" bounty](https://make.fun/competitions/u-kreutzx-one-line-robot-wedding-vows-a154ba4b): a one-line robot wedding vow that runs the classic wedding line through firmware updates and lands on airplane mode.

> I promise to love you through every firmware update, every low battery, and every reboot — in sickness, in health, and in airplane mode.

`main.ts` deterministically writes exactly that line (136 characters, one line, no trailing newline) to `/output/entry.txt`. No randomness, no network, no input.
